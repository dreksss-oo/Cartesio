# Changelog

## 3.13.0
- Nome definitivo: **Cartesio** (app, eseguibile, file `.cartesio`; i progetti `.curva` si aprono ancora e i dati della versione precedente vengono migrati).
- Linguaggio esteso: scale e modi, accordi, inviluppi, sintesi (FM, AM, PWM, supersaw, wavefolding, bitcrush), operazioni sui bit, liste, funzioni speciali.
- Sorgenti riorganizzati per GitHub (stile, motore, processore audio e interfaccia separati).
